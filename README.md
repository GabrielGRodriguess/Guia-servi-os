# Guia Serviços - Rede Técnica ETEC

O **Guia Serviços** é uma plataforma de marketplace local voltada para a conexão entre moradores da região e profissionais técnicos qualificados. O projeto possui um forte posicionamento institucional, com destaque especial para **alunos e ex-alunos da ETEC**.

## 🚀 Proposta do Projeto
Diferente de um guia genérico, o app foca na **qualidade técnica** e na **comunidade educacional**. Ele permite que técnicos recém-formados ou experientes divulguem seus serviços, enquanto usuários encontram mão de obra confiável com o selo de formação técnica.

## 🛠️ Tecnologias Utilizadas
- **React 19** + **Vite 6**
- **Framer Motion** para animações e modais
- **Lucide React** para iconografia técnica
- **LocalStorage** para persistência de dados local
- **CSS3 Vanilla** com design system customizado

## ✨ Funcionalidades Principais
- **Filtro por Cidade e Categoria**: Busca intuitiva por serviços em diversas cidades da região.
- **Destaque ETEC**: Sistema de selos para profissionais com vínculo comprovado.
- **Painel Administrativo**: Gestão completa de prestadores, aprovação de perfis e moderação.
- **Perfil Detalhado**: Visualização de experiência, formação técnica, fotos e botão direto para WhatsApp.
- **Cadastro Simplificado**: Fluxo intuitivo para novos prestadores entrarem na rede.
